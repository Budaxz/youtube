Este repositório contém o projeto desenvolvido durante os estudos no curso de Programação de Sistemas pelo SENAI, com foco na implementação de uma interface dinâmica e responsiva utilizando ReactJS e a biblioteca Owl Carousel.

✨ Funcionalidades Principais

O projeto demonstra a aplicação prática dos seguintes conceitos:
Carrossel Interativo: Implementação de um slider utilizando a biblioteca Owl Carousel para exibição de conteúdo.
Componentização: Estrutura clara de componentes React, promovendo modularidade e reutilização.
Responsividade: Garantia de adaptação visual correta em diferentes tamanhos de tela.
Integração de Bibliotecas: Uso eficiente de bibliotecas externas dentro do ciclo de vida de um componente React.

🛠️ Tecnologias Utilizadas

Front-End: ReactJS
Carrossel: Owl Carousel
Linguagem: JavaScript (ES6+)
Estilização: CSS Puro

📚 Aprendizados

Esta experiência foi crucial para reforçar:

- A manipulação correta de bibliotecas de terceiros no ambiente React.
- A importância da lógica de programação aplicada ao state e props para o controle do carrossel.
- O uso de boas práticas no desenvolvimento Front-End.
